# Jump Collect Explorer — production image prompts

Generate every asset with the same visual language: premium family-friendly casual mobile game, original stylized 2.5D illustration, soft rounded forms, polished clay-like materials mixed with painterly detail, saturated but sophisticated color palette, cinematic rim light, soft ambient occlusion, clean readable silhouette, subtle depth, no photorealism, no horror, no watermark. Do not imitate an existing game or franchise.

For transparent assets request PNG with a true alpha background, no floor, no frame, no text, and at least 12% empty padding on every side. Keep the light source at the upper left for every asset.

## Delivery requirements

- Do not place several requested assets in one image.
- Preserve transparent pixels; do not use a checkerboard or colored backdrop.
- Keep character proportions identical across every skin.
- Keep platforms in the same camera angle and landing-surface perspective.
- Do not bake labels, counters or button text into assets except the main logo and the `2×` egg symbol.
- Export foreground assets as PNG, not JPEG.
- Keep each filename exactly as written above; the app texture factory will use these names.
