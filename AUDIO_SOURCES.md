# Audio sources

The sound effects in `Resources/Sounds` are adapted from the following Kenney asset packs:

- Interface Sounds — https://kenney.nl/assets/interface-sounds
- Impact Sounds — https://kenney.nl/assets/impact-sounds
- Casino Audio — https://kenney.nl/assets/casino-audio

All three packs are published under Creative Commons CC0. The original Kenney license file is included alongside the converted sound files.

Processing applied for the game: mono mixdown, silence trimming, peak normalization, short fades, and conversion to 16-bit PCM WAV at 44.1 kHz.
